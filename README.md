# DB Heating, Cooling & Refrigeration

Official website for DB Heating, Cooling & Refrigeration — providing professional heating, air conditioning, HVAC system maintenance, and commercial refrigeration solutions in Greenville, NY.

## Tech Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: JavaScript (ESNext)

## Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Sajith-Mathavaraja/DB-Heating-Cooling-Refrigeration.git
   cd DB-Heating-Cooling-Refrigeration
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
